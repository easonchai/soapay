`@soapay/sdk` is the protocol boundary for every Soapay app. It is a private workspace package today. Add it to another workspace package as `"@soapay/sdk": "workspace:*"`, then build it before consuming its `dist` output. A Node entry point must also follow the bundling rule below.

```bash
pnpm --filter @soapay/sdk build
```

Most exports come from `@soapay/sdk`. ENSv2 exports are also available from `@soapay/sdk/ensv2`.

## Node and the ScopeLift dependency

`@scopelift/stealth-address-sdk@1.0.0-beta.5` is ESM but contains extensionless and directory imports. Plain Node loading fails with `ERR_UNSUPPORTED_DIR_IMPORT`. Use one of these supported paths:

- Bundle a Node entry point with esbuild, as the API, CLI, and MCP packages do.
- Run TypeScript through `tsx`.
- Inline the dependency in Vitest with `server.deps.inline: ["@scopelift/stealth-address-sdk"]`.
- Let Vite bundle browser code.

Do not publish a Node entry point that imports the SDK output without one of those treatments.

## Derivation: `keys.ts`

| Export | Purpose |
| --- | --- |
| `generateMnemonic(strength: 128 \| 160 \| 192 \| 224 \| 256 = 128): string` | Generate an English BIP-39 phrase, 12 words by default |
| `validateMnemonic(mnemonic: string): boolean` | Validate its word list and checksum |
| `keysFromMnemonic(mnemonic: string, passphrase?: string): SoapayKeys` | Derive spending, viewing, and registrant keys deterministically |
| `parseMetaAddress(input: string): Hex` | Validate a URI or raw 66-byte scheme-1 meta-address |
| `formatMetaAddressURI(metaAddress: string): string` | Return canonical lowercase `st:eth:0x...` form |
| `assertPlainEoa(address: Address, code: Hex \| undefined): void` | Reject wallet-signature derivation for accounts with code |
| `assertPlainEoaSignature(params: { address: Address; code: Hex \| undefined; signature: Hex }): Promise<void>` | Validate a plain 65-byte ECDSA wallet signature |
| `keysFromSignature(signature: Hex): SoapayKeys` | Derive keys from the fixed `SIGN_MESSAGE` signature |
| `keysFromWalletSignature(params: { address: Address; code: Hex \| undefined; signature: Hex; confirmSignature?: Hex \| undefined }): Promise<SoapayKeys>` | Run all plain-EOA and determinism checks, then derive keys |

`SoapayKeys` contains secret `spendingKey`, `viewingKey`, and `registrantKey` values plus `spendingPublicKey`, `viewingPublicKey`, `registrantAddress`, and `metaAddressURI`. The BIP-32 paths are `m/5564'/1'/0'`, `m/5564'/1'/1'`, and `m/5564'/1'/2'`.

```ts
import { generateMnemonic, keysFromMnemonic } from "@soapay/sdk";

const phrase = generateMnemonic();
const keys = keysFromMnemonic(phrase);
console.log(keys.metaAddressURI);
```

## Announce and pay runs: `payrun.ts`

| Export | Purpose |
| --- | --- |
| `compareAddresses(a: Address, b: Address): number` | Compare addresses numerically |
| `derivePayRun(params: DerivePayRunParams): PayRunLine[]` | Derive fresh lines, globally sort them, and reject repeats |
| `assertPayRunInvariants(lines: readonly PayRunLine[]): void` | Check amount, order, address, and ephemeral-key invariants |
| `chunkLines<T>(lines: readonly T[], max: number = MAX_LINES_PER_TX): T[][]` | Make balanced consecutive chunks |
| `encodeHead(f: HeadFields): bigint` | Pack address, uint80 amount, view tag, and key prefix |
| `decodeHead(head: bigint): HeadFields` | Decode the packed word |
| `buildMetadata57(m: MetadataFields): Hex` | Encode standard ERC-5564 ERC-20 metadata |
| `buildMetadata77(m: MetadataFields & { payer: Address }): Hex` | Append the StealthDisperse payer hint |
| `packLine(l: PayRunLine): PackedPayment` | Convert a derived line to the contract tuple |
| `encodeStealthDisperseCalls(params: { stealthDisperse: Address; token: Address; lines: readonly PayRunLine[]; maxLinesPerTx?: number }): StealthDisperseCalls` | Encode exact-total approval plus `pay` calls |
| `encodeBatchCalls(params: { token: Address; lines: readonly PayRunLine[]; announcer?: Address; maxLinesPerTx?: number }): BatchCallsChunk[]` | Encode atomic transfer and announce pairs for EIP-5792 |
| `estimatePayRunGas(lines: readonly PayRunLine[], maxLinesPerTx: number = MAX_LINES_PER_TX): PayRunEstimate` | Return line, recipient, transaction, amount, and gas totals |

```ts
import { derivePayRun, encodeStealthDisperseCalls } from "@soapay/sdk";

const lines = derivePayRun({
  recipients: [{ metaAddressURI, amount: 1_000_000n, id: "alice" }],
});
const calls = encodeStealthDisperseCalls({ stealthDisperse, token, lines });
```

The ABI exports are `announcerAbi`, `registryAbi`, `stealthDisperseAbi`, `offchainResolverAbi`, `resolverServiceAbi`, `resolverRecordsAbi`, and `erc20Abi`.

## Scan: `scan.ts`

| Export | Purpose |
| --- | --- |
| `fetchAnnouncements(params: { apiUrl: string; fromBlock?: bigint; toBlock?: bigint; limit?: number; maxPages?: number; fetch?: FetchLike }): Promise<{ announcements: AnnouncementRecord[]; skipped: number }>` | Page through the API index |
| `fetchAnnouncementsRpc(params: { client: LogsClient; fromBlock: bigint; toBlock: bigint; chunkSize?: number; concurrency?: number; announcer?: Address }): Promise<AnnouncementRecord[]>` | Fetch and sort Announcer logs over RPC |
| `parseMetadata(metadata: Hex): MetadataHints \| null` | Parse 57-byte or 77-byte untrusted metadata |
| `metadataViewTag(metadata: Hex): number \| undefined` | Read the first metadata byte |
| `scanAnnouncementsWithStats(announcements: readonly AnnouncementRecord[], keys: ScanKeys): { matches: ScanMatch[]; stats: ScanStats }` | Apply the view-tag prefilter and full ownership check |
| `scanAnnouncements(announcements: readonly AnnouncementRecord[], keys: ScanKeys): ScanMatch[]` | Return matches without statistics |
| `deriveStealthKey(match: Pick<ScanMatch, "announcement">, keys: { spendingPrivateKey: Hex; viewingPrivateKey: Hex }): Hex` | Derive and verify the private key controlling a match |
| `verifyBalances(params: { client: MulticallClient; matches: readonly Pick<ScanMatch, "announcement">[]; tokens: readonly Address[] }): Promise<BalanceRow[]>` | Read real token balances with multicall |
| `buildLedger(matches: readonly ScanMatch[], balances: readonly BalanceRow[], knownPayers: readonly Address[] = [], opts: { stealthDisperse?: readonly Address[] } = {}): LedgerEntry[]` | Build trusted balance rows with payer and metadata flags |

```ts
const { announcements } = await fetchAnnouncements({ apiUrl, fromBlock });
const { matches, stats } = scanAnnouncementsWithStats(announcements, {
  spendingPublicKey: keys.spendingPublicKey,
  viewingPrivateKey: keys.viewingKey,
});
const balances = await verifyBalances({ client: publicClient, matches, tokens: [usdc] });
const ledger = buildLedger(matches, balances, [knownPayer], { stealthDisperse: [disperse] });
```

## Spend: `spend.ts`

| Export | Purpose |
| --- | --- |
| `parseDelegationDesignator(code: Hex \| undefined \| null): Address \| null` | Decode exact EIP-7702 designator bytecode |
| `isDelegated(client: Pick<PublicClient, "getCode">, address: Address, expected: Address = SIMPLE_7702_ACCOUNT): Promise<DelegationStatus>` | Classify an EOA, delegation, or contract |
| `createSpendClient<chain extends Chain = Chain>(options: CreateSpendClientOptions<chain>): SpendClient` | Configure chain RPC, bundler, and paymaster |
| `resolvePaymaster(chainId: number, mode: CreateSpendClientOptions["paymaster"], paymasterUrl?: string): PaymasterAdapter` | Resolve Circle or sponsored gas behavior |
| `buildTransferCall(token: Address, to: Address, amount: bigint): SpendCall` | Encode one ERC-20 transfer |
| `maxSendable(balance: bigint, fee: bigint): bigint` | Subtract a fee without going below zero |
| `estimateSpend(client: SpendClient, params: SpendParams): Promise<SpendEstimate>` | Prepare and price a transfer user operation |
| `estimateExecute(client: SpendClient, params: ExecuteParams): Promise<ExecuteEstimate>` | Prepare and price arbitrary zero-value calls |
| `executeFromStealth(client: SpendClient, params: ExecuteParams, options: SpendOptions = {}): Promise<ExecuteResult>` | Send one user operation from one stealth address |
| `spendFromStealth(client: SpendClient, params: SpendParams, options: SpendOptions = {}): Promise<SpendResult>` | Transfer a fixed amount or `"max"` |
| `spendMany(client: SpendClient, spends: readonly SpendParams[], options: SpendManyOptions = {}): Promise<SpendResult[]>` | Send sequentially, one user operation per address |

`SpendParams` is `{ stealthKey, to, amount, token?, maxFeeUsdc? }`. `ExecuteParams` is `{ stealthKey, calls, maxFeeUsdc?, feeTokenSpend?, allowValue? }`. The default fee cap is `1_000_000n`, one USDC in base units.

```ts
const spend = createSpendClient({
  chainId: 84532,
  bundlerUrl: "https://public.pimlico.io/v2/84532/rpc",
  publicClient,
  paymasterUrl: `${apiUrl}/paymaster`,
  estimateFeesPerGas: pimlicoFeesPerGas,
});

const stealthKey = deriveStealthKey(match, {
  spendingPrivateKey: keys.spendingKey,
  viewingPrivateKey: keys.viewingKey,
});
await spendFromStealth(spend, { stealthKey, to, amount: "max" });
```

The spend module also exports the `PaymasterAdapter` types, Circle, Pimlico, and sponsored adapters. `pimlicoErc20Paymaster` is experimental and not live-verified.

Only the Trading API `quote` endpoint is used. The SDK never sends a stealth address to the quote service and never asks it to build the final swap calldata. The web employee app has no swap screen; this API is available to SDK and MCP integrators.

## Exit: `exit.ts`

The exit is a serializable, resumable state machine. Its main public surface is:

Only `84532:11155111`, Base Sepolia to Ethereum Sepolia, is configured. The default Base Sepolia pay token is MockUSDC, so `exitAvailability` disables the route unless the source uses Circle USDC.
