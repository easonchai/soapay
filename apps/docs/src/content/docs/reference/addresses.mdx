These are the addresses selected by the SDK and used by the live Base Sepolia deployment. The canonical ERC-5564 Announcer and ERC-6538 Registry use the same addresses across supported chains. Base Sepolia is the current payroll network; Ethereum Sepolia hosts ENSv2 names and the test exit destination.
