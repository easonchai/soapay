Defaults below come from application code. An empty value means unset unless another fallback is shown. Values prefixed with `VITE_` are compiled into browser bundles and must never contain secrets.

## Company app (`apps/sender`)

| Variable | Meaning | Default |
| --- | --- | --- |
| `VITE_CHAIN_ID` | Pay chain | `84532` |
| `VITE_STEALTH_DISPERSE` | Plain-account batch contract | SDK chain deployment, or empty |
| `VITE_STEALTH_DISPERSE_ADDRESS` | Alias for the preceding variable | empty |
| `VITE_RPC_URL` | Pay-chain RPC | public chain RPC |
| `VITE_ENS_RPC_URL` | ENS-chain RPC | public chain RPC |
| `VITE_PAY_TOKEN` | Base Sepolia pay-token override | Soapay mock USDC |
| `VITE_API_URL` | Soapay API base | `http://localhost:8787` |
| `VITE_ATTESTER` | Pinned rotation attester | empty, manual approval required |
| `VITE_RECIPIENT_URL` | Invite-link base | `http://localhost:5173` |
| `VITE_OTHER_APP_URL` | Receive navigation link | recipient URL |
| `VITE_DOCS_URL` | Documentation link | `/docs/` |
| `VITE_WALLETCONNECT_PROJECT_ID` | Optional WalletConnect connector | empty |
| `VITE_MOCK_ENS` | Development-only name and attestation mocks | `0` |
| `VITE_DEMO` | Default in-browser demo mode | unset |

## CLI (`apps/cli`)

| Variable | Meaning | Default |
| --- | --- | --- |
| `PAYER_PRIVATE_KEY` | Sender key for `distribute --execute` | secret, never commit; required to execute |
| `PAY_TOKEN` | Base Sepolia token override | Soapay mock USDC |
| `SOAPAY_API_URL` | Rotation-attestation API | live API on chain `84532` |
| `SOAPAY_ATTESTER` | Pinned rotation signer | deployed attester on chain `84532` |
| Variable named by `--mnemonic-env` | Recovery phrase used by `scan` | secret, never commit; required |

Command flags provide RPC, ENS RPC, API, attester, and contract overrides. The CLI is dry-run by default.

## Documentation (`apps/docs`)

| Variable | Meaning | Default |
| --- | --- | --- |
| `SITE_ORIGIN` | Canonical site and sitemap origin | `https://soapay.up.railway.app` |

The docs always build with base path `/docs`. The deployment script passes the public origin as `SITE_ORIGIN`; it does not change the route base. See [Architecture](/docs/reference/architecture/) for how the static site and API are served.
