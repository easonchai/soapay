Defaults come from code. Empty means unset. Browser-exposed `VITE_` values must never contain secrets.

## Company app (`apps/sender`)

| Variable | Meaning | Default |
| --- | --- | --- |
| `VITE_CHAIN_ID` | Pay chain | `84532` |
| `VITE_STEALTH_DISPERSE` / `VITE_STEALTH_DISPERSE_ADDRESS` | Batch contract and alias | SDK deployment / empty |
| `VITE_RPC_URL` / `VITE_ENS_RPC_URL` | Pay and ENS RPCs | public RPCs |
| `VITE_PAY_TOKEN` | Base Sepolia pay-token override | Soapay mock USDC |
| `VITE_API_URL` | Soapay API base | `http://localhost:8787` |
| `VITE_ATTESTER` | Pinned rotation attester | empty, manual approval required |
| `VITE_RECIPIENT_URL` / `VITE_OTHER_APP_URL` / `VITE_DOCS_URL` | Invite, Receive, and Docs links | `http://localhost:5173` / recipient URL / `/docs/` |
| `VITE_WALLETCONNECT_PROJECT_ID` | Optional WalletConnect connector | empty |
| `VITE_MOCK_ENS` / `VITE_DEMO` | Development mocks and default demo mode | `0` / unset |
